# Books TIGER 保留原权重的扩容实验

从 2026-10-28 低学习率续训选出的第 21 轮小模型出发，扩大网络后继续训练。旧的随机初始化宽版实验保持暂停，原最佳模型保留。

| 项目 | 原模型 | 本轮 |
|---|---:|---:|
| 参数量 | 5,043,712 | 14,281,344（2.83 倍） |
| 主特征宽度 d_model | 128 | 256 |
| FFN 宽度 d_ff | 1,024 | 2,048 |
| Encoder / Decoder | 4 / 4 | 4 / 4 |
| heads / d_kv | 6 / 64 | 6 / 64 |

不是从头随机训练。复制残差通道和 FFN 神经元，对输入投影作分摊，保留注意力内部宽度，并补偿共享词嵌入输出的 T5 缩放。扩容后 FP32、关闭 dropout 的预测函数应与原模型一致。训练期独立 dropout 会打破复制通道的对称性，测试检查该行为。

BF16 舍入不保证完全一致，因此正式训练前既核验 FP32 logits/loss，又在全部固定验证用户上复现小模型和检查大模型初始指标。预设允许漂移不超过 Recall@10 0.10 个百分点、NDCG@10 0.00025，超限退出，不启动正式参数更新。

训练配置：全量每轮 7,087,037 个训练样本，batch=512、BF16、AdamW reset、峰值学习率 3e-5，500 步预热后余弦至 3e-6，weight decay=0.01，梯度裁剪=1。最多追加 3 轮（累计 22–24），连续 2 轮验证 NDCG@10 无改善早停；扩容初始化也参与选模。数据、语义编码、最近 20 件历史、原固定 20,000 验证用户、beam=20 和全历史过滤保持一致。

最终只对所选权重评估全部 603,668 测试用户一次，并与父模型测试 Recall@10=3.371555%、NDCG@10=0.02086758 比较。单种子、同时增加参数和更新步数，不能把全部变化归因于容量；没有增加一条匹配预算的小模型续训对照。

```bash
cd /root/autodl-tmp/deeplearning-lab/recommendation/generative_books
bash tiger_growth/start_train.sh
tail -f "$(cat runs/latest_tiger_growth.txt).log"
```

运行通过 `pipeline.lock` 排他启动，最多 7,200 秒停止实验进程。用户要求保持机器开机，启动脚本不关机。数据和权重只留在远端；本机保存代码和小型结果文件。

短跑使用分散抽取的 16,384 个训练样本和 64 个验证用户，验证权重扩展、训练/保存/恢复和评估链路，不用于报告质量提升。

加载大模型时必须先通过 `growth.expand_tiger` 构造 256/2048 结构，再加载本轮 checkpoint；原小模型的默认 `create_model` 不能直接加载宽版权重。运行目录同时保存本轮源码与继承的小模型源码快照。
