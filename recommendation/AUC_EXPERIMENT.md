# AUC 选模、显式交互和 DeepFM 对照实验

> 历史实验记录：代码于 2026-10-22 与远端核对归档；下文成绩和运行状态仍来自此前实验，本次没有复训。数据、图表与模型产物不随 Git 分发。

本轮针对上一版完整特征模型继续实验。三种模型都使用用户/电影 ID、性别、年龄段、职业、电影类型、发行年份、过去高评分电影以及历史评分统计。数据、标签、时间划分和历史特征定义一致。

## 三种模型

| 名称 | 结构 | 前馈网络输入维度 | 参数量 |
|---|---|---:|---:|
| `mlp` | 原来的完整特征 MLP，一个 64 维隐藏层 | 253 | 560,893 |
| `interaction` | MLP 加用户×电影、历史偏好×电影的逐元素乘积及两项点积 | 383 | 569,213 |
| `deepfm` | 一阶线性项 + 二阶 FM 交互 + 一个 64 维隐藏层，共享 embedding | 3,008 | 750,277 |

三种模型的用户、电影向量都是 64 维。交互版在相同种子下复制 MLP 初始权重，新增交互列从零开始学习，因此初始预测与 MLP 一致。

DeepFM 把 5 个类别字段、41 个数值/类型字段转换为 64 维因子。历史电影共享候选电影的 embedding，按有效历史数量归一化。FM 分支计算类别、数值、历史电影这些加权因子的所有两两内积；前馈分支拼接类别 embedding、历史平均向量、各数值字段的加权 embedding。最终将线性项、FM 项、前馈输出相加，再经 Sigmoid 得到分数。

结构参考 [DeepFM 原论文](https://www.ijcai.org/proceedings/2017/0239.pdf) 中共享 embedding、线性项与二阶交互和前馈网络联合训练的设计。本实现适配当前 MovieLens 属性及历史特征，保留一个隐藏层，**不是论文参数或论文指标的复现**。DeepFM 编码宽度及参数量也不同，因此这是三个完整方案的比较，不能把差异全部归因于单个交互操作。

## 预先确定的实验规则

1. 种子 42 比较全部三种模型，统一按验证 AUC 保存和早停。
2. 在 `interaction` 与 `deepfm` 中，仅按种子 42 的最佳验证 AUC 选出候选。
3. 原 MLP 与该候选再运行种子 43、44，共 7 次训练。
4. 用三个种子的平均验证 AUC 选择模型方案；代表 checkpoint 固定取种子 42，不按测试结果挑种子。
5. 全部模型和选择固定之后，才对各个 `best_auc.pt` 计算测试指标。

协议保存在 `protocol.json`，第一阶段选择保存在 `validation_selection.json`，最终选择保存在 `final_selection.json`。这些选择文件在本轮测试评估之前写入。

统一训练参数：AdamW、学习率 0.001、weight decay 0.0001、batch size 4,096、最多 50 轮、patience=10、min_delta=0.0001、梯度裁剪 5。学习率固定，没有新增 Dropout；本轮先比较模型结构，未同时搜索正则化参数。每个种子内，各模型每轮训练样本顺序相同，并与模型初始化使用独立随机数生成器。

每轮分别保存最高 AUC 和最高 NDCG 的模型。小于 min_delta 的 AUC 改善仍会更新最佳 checkpoint，但不会立即重置早停计数。

## 数据和指标

- 训练 700,144 条、验证 35,124 条、测试 75,930 条；ID 词表覆盖 4,870 名用户和 3,633 部电影。
- 完全复用之前保存的时间划分，并逐项校验属性表与冻结历史和上一轮一致。相同时间戳的评分互相不可见，验证/测试不反馈评分到历史。
- 标签仍是是否达到 4 星。AUC、Log loss 和阈值 0.5 的二分类准确率基于全部保留样本。
- NDCG@10 在同一用户已经评分的候选中计算，只有同时有高分和低分的用户参与；不是全库召回/排序效果，也不是点击率。
- 每轮日志和 `metrics.csv` 现在记录训练准确率、验证准确率、AUC、NDCG、训练/验证损失。训练准确率是在各批次更新时累计的，不是 epoch 结束后的独立训练集评估。
- 三个种子的均值和标准差反映优化随机性的变化，不是三个独立数据集，也不是置信区间。当前测试集此前已被查看过，本轮仍属于探索性对照。

## 完成结果

7 次训练、特征准备和测试评估共约 **274.6 秒（4.6 分钟）**。所有 checkpoint 固定后才进行本轮测试评估。

种子 42 的第一阶段结果如下，三个模型使用完全相同的测试样本：

| 模型 | 最佳验证 AUC | 测试 AUC | 测试 NDCG@10 | 测试准确率 |
|---|---:|---:|---:|---:|
| 原 MLP | 0.78713 | 0.76467 | 0.83203 | 69.57% |
| MLP 加显式交互 | 0.77941 | 0.75887 | 0.82308 | 68.95% |
| DeepFM | **0.78861** | **0.77142** | **0.83490** | **70.31%** |

仅根据首轮验证 AUC 选择 DeepFM 与原 MLP 进行种子 43、44 的复核。三个种子的测试汇总（均值 ± 样本标准差）为：

| 指标 | 原 MLP | DeepFM |
|---|---:|---:|
| AUC ↑ | 0.76448 ± 0.00051 | **0.77086 ± 0.00064** |
| NDCG@10 ↑ | 0.83200 ± 0.00270 | **0.83506 ± 0.00053** |
| 准确率 ↑ | 69.53% ± 0.05 个百分点 | **70.20% ± 0.10 个百分点** |
| Log loss ↓ | 0.60016 ± 0.01026 | **0.58378 ± 0.00156** |

DeepFM 相对原 MLP 的三次配对测试 AUC 差值分别为 **+0.00675、+0.00626、+0.00615**；平均增加 **0.00639**。平均准确率增加约 **0.68 个百分点**，NDCG@10 增加 **0.00306**。三个种子方向一致，但仍只说明同一时间划分下的结果，不能替代新数据验证。

显式交互版在首轮验证集和测试集都较差，因此没有继续扩展它的种子。这说明直接添加乘积/点积特征并不保证改善；本轮 DeepFM 的完整结构更有效。

最终模型方案同样按验证集决定：DeepFM 的三种子平均验证 AUC 为 0.79016，原 MLP 为 0.78545。代表模型按照预定规则选择 **`deepfm/seed42/best_auc.pt`**；没有按测试表现选择种子。

各模型均通过 CPU 重载与 GPU 输出对照。进一步核对了 7 组的测试行号与标签、AUC/NDCG 最佳 checkpoint 与逐轮指标、导出向量，并实际调用独立推理脚本；示例分数最大差异小于 0.0000003。测试集仍是 75,930 条已知用户、已知电影的评分记录，准确率对应「是否打 4～5 星」，不是五档评分预测准确率。

## 运行位置与命令

本轮 AutoDL 目录：`/root/autodl-tmp/deeplearning-lab/recommendation/runs/auc-20261007-100354`。

查看本轮日志：

```bash
tail -f /root/autodl-tmp/deeplearning-lab/recommendation/runs/auc-20261007-100354.log
```

日志以 `[mlp/seed42]`、`[interaction/seed42]` 等标识具体实验。所有训练完成后会出现 `ALL_CHECKPOINTS_FIXED`，随后输出测试结果，最后为 `EXPERIMENT_COMPLETE`。

重新运行默认的完整协议：

```bash
cd /root/autodl-tmp/deeplearning-lab/recommendation
bash start_auc.sh
```

只运行第一阶段的三组单种子对照：

```bash
cd /root/autodl-tmp/deeplearning-lab/recommendation
bash start_auc.sh --seeds 42
```

每次运行生成独立目录，不覆盖之前的模型。启动脚本会先运行历史防泄漏、FM 公式、共享梯度、空历史处理和模型重载检查。

## 模型与结果文件

每个 `模型名/seed种子/` 子目录保存：

| 文件 | 内容 |
|---|---|
| `best_auc.pt` | 本轮主选模指标对应的模型，测试评估和推荐推理均使用它 |
| `best_ndcg.pt` | 另存的最佳验证 NDCG 模型，本轮不额外用它挑测试结果 |
| `best.pt` | `best_auc.pt` 的相同副本 |
| `metrics.csv` | 每轮完整训练/验证指标 |
| `config.json` | 超参数、结构、数据与源码哈希 |
| `training_summary.json` | 最佳轮数、训练时长、梯度检查，不含测试结果 |
| `summary.json` | 最佳 AUC 模型的验证和测试指标 |
| `test_predictions.npz` | 原始用户/电影 ID、标签和逐样本分数 |
| `user_embeddings.npz` / `item_embeddings.npz` | 两张 64 维 ID 向量表 |

实验根目录的 `summary.json` 保存所有实验、各模型的多种子均值/标准差以及与原 MLP 逐种子配对的指标差值。数据划分、属性表、历史快照、源码快照及哈希一并保存。

推理使用 `score_auc.py`，checkpoint 内含映射、属性、历史状态与全部模型权重。以下示例调用本轮选出的 DeepFM 代表模型，其他模型替换 checkpoint 路径即可：

```bash
cd /root/autodl-tmp/deeplearning-lab/recommendation
/root/miniconda3/bin/python score_auc.py \
  --checkpoint /root/autodl-tmp/deeplearning-lab/recommendation/runs/auc-20261007-100354/deepfm/seed42/best_auc.pt \
  --user-id 1164 \
  --item-ids 2987 715 1249 2996 728 587 589 1 6 3006
```

该调用只对给定候选打分，不包含候选召回或已看电影过滤。旧的 `score.py`、`score_features.py` 继续对应旧版模型，不适用于新增的交互版与 DeepFM。
